## 3. The 12 Advanced Test Groups & Verification Invariants

### Group 1: Excel Round-Trip Testing (`ExcelRoundTripTests.cs`)
- **Objective:** Verify that workbooks generated by Spreadox can be opened, inspected, and modified by third-party OpenXML tools (the official Microsoft OpenXML SDK), saved back to disk, and reloaded by Spreadox without corruption or data loss.
- **Invariants Tested:**
  - Cell string values and exact numeric values are preserved.
  - Cell formatting (e.g. bold font) remains intact.
  - Calculated formulas and pre-computed cached values survive round-trip.
  - Merged cell ranges (`B2:D3`) remain registered and intact.
  - Split/Freeze panes (`FreezePanes(2, 1)`) survive modifications.
  - DrawingML Chart parts, series references (`B2:B5`), and category ranges (`A2:A5`) remain intact.
  - Embedded image drawings (`DrawingsPart`) and relationships survive.
- **Result:** **PASS (0 structural errors, 0 data mutations)**.

### Group 2: Property-Based Testing (`PropertyBasedTests.cs`)
- **Objective:** Generate randomized but structurally valid inputs across mathematical domains to discover coordinate drift, off-by-one errors, and encoding boundaries.
- **Scenarios & Invariants:**
  - **10,000 Randomized Cell Coordinates:** Generates random row indices `[1..1,048,576]` and columns `[1..16,384]`. Verifies `CellAddress.Format(row, col) <-> CellAddress.Parse(address)` bidirectional round-trip holds with 100% mathematical fidelity.
  - **2,000 Randomized 2D Cell Ranges:** Generates arbitrary bounding rectangles `(r1, c1, r2, c2)`. Invariant: `CellRange.Parse(range.Address)` preserves row and column bounds regardless of ordering.
  - **Color Representation:** 1,000 random RGB combinations verify `ExcelColor.FromRgb(r, g, b).ToHex()` produces exact 6-character uppercase hex strings.
  - **Numeric Precision:** High-precision double values preserve exact binary representation when stored and retrieved.
- **Result:** **PASS (10,000/10,000 coordinates, 2,000/2,000 ranges valid)**.

### Group 3: Fuzz Testing & Resilience (`FuzzTestingTests.cs`)
- **Objective:** Subject Spreadox ingestion and packaging pipelines to malformed, truncated, and adversarial data to ensure safe failure modes (throwing typed exceptions without crashing the CLR or corrupting process state).
- **Adversarial Scenarios Tested:**
  - **Corrupted Byte Streams:** Random garbage bytes fed into `ExcelWorkbook.Open` throw `InvalidDataException` / `OpenXmlPackageException` gracefully.
  - **Truncated ZIP Archive:** A valid XLSX package truncated at 25%, 50%, and 75% of its byte length throws predictable archive corruption exceptions.
  - **Extreme Cell Content (50,000 characters):** Exceeding typical single-cell length; correctly serializes to XML inline strings and SST without memory exhaustion.
  - **XML 1.0 Control Character Fuzzing:** Strings containing illegal characters (`\0`..`\x1F` except `\t`, `\r`, `\n`) are stripped/sanitized by `SanitizeXmlString`, preventing unhandled XML serializer termination.
  - **Corrupted Font Streams:** Feeding corrupted TrueType header bytes into `PdfFontRegistry.Register` throws `ArgumentException` without damaging subsequent font resolutions.
- **Result:** **PASS (Controlled typed exceptions, zero CLR crashes)**.

### Group 4: Formula Compatibility & Security (`ExcelFormulaCompatibilityTests.cs`)
- **Objective:** Validate formula XML generation, regional separator handling, and protection against CSV/Formula Injection (DDE attacks).
- **Formulas Tested:**
  - `SUM(A1:A5)` with pre-computed cached values.
  - `AVERAGE(B1:B10)` with decimal results.
  - `COUNT(C1:C100)` for integer frequency.
  - `IF(A1>50, 1, 0)` conditional expressions.
  - Nested expressions: `SUM(A1:A5) * 1.18 + IF(B1 > 100, 10, 0)`.
- **Security Validation:**
  - Validates that formula injection payloads (e.g. `=cmd|' /C calc'!A0` or `-2+3+cmd|...`) when set as cell *values* are treated as pure text strings rather than executable formulas, preventing client-side spreadsheet execution.
- **Result:** **PASS (Accurate formula XML tags `<f>` and `<v>`, injection payloads neutralized)**.

### Group 5: Style Explosion & Deduplication (`ExcelStyleExplosionTests.cs`)
- **Objective:** Test behavior under massive styling pressure to prevent `styles.xml` bloat and ensure style deduplication.
- **Scenarios:**
  - **10,000 Cells with Identical Styling:** A streaming worksheet writes 10,000 cells with the exact same font, size, and background color. Invariant: Internal style deduplication collapses these into `<= 5` unique `cellXfs` style records in `styles.xml`, keeping the file size compact.
  - **200 Distinct Combinations:** 200 distinct font sizes and colors are generated. Validates that OpenXmlValidator confirms 100% schema validity with zero font, fill, or border ID collisions.
- **Result:** **PASS (styles.xml size remains < 12 KB, 0 schema collisions)**.

### Group 6: Streaming Failure Recovery (`StreamingFailureRecoveryTests.cs`)
- **Objective:** Test error recovery, stream disposal, and fault tolerance when the output stream fails mid-generation (e.g., disk full, broken socket).
- **Scenarios:**
  - **Disk Full / Broken Stream Simulation:** A custom `FaultyStream` throws `IOException: Disk full` after writing 25,000 bytes during a 50,000-row export. Invariant: Spreadox propagates `IOException` cleanly, and wrapping `using` statements guarantee the underlying stream is properly disposed without unmanaged memory locks.
  - **Row Ordering Invariant:** SAX streaming requires monotonic row ordering (`r1 < r2`). Attempting to write row 5 after row 10 immediately throws `InvalidOperationException` rather than producing an unopenable corrupt XLSX file.
  - **Disposed Workbook Protection:** Calling methods on an already disposed `ExcelStreamingWorkbook` immediately throws `ObjectDisposedException`.
- **Result:** **PASS (Zero unmanaged file locks, strict state encapsulation)**.

### Group 7: Decimal & Financial Precision (`DecimalAndFinancialPrecisionTests.cs`)
- **Objective:** Guarantee financial figures, decimal fractions, and currency amounts do not suffer from IEEE 754 floating-point drift or scientific notation corruption.
- **Precision Invariants Tested:**
  - `0.1m + 0.2m = 0.3m` exact decimal arithmetic.
  - Large financial values: `999,999,999,999.99m` (trillion minus one cent).
  - High precision rates: `0.00000001m` (8 decimal places for crypto / FX rates).
  - Negative micro-cents: `-0.0001m`.
  - Boundary limits: `decimal.MaxValue` and `decimal.MinValue` handled without overflow exceptions.
  - Currency number formats: `NumberFormats.Currency` (`$#,##0.00`) and Turkish Lira formats.
- **Result:** **PASS (Exact decimal numbers preserved across OpenXml round-trip without float drift)**.

### Group 8: Excel Limits & Boundary Testing (`ExcelBoundaryTests.cs`)
- **Objective:** Verify compliance with strict OOXML / Excel architectural limits.
- **Limits Tested:**
  - **Max Rows:** Exactly 1,048,576 rows (`MaxRows`). Attempting row `1,048,577` throws `ArgumentOutOfRangeException`.
  - **Max Columns:** Exactly 16,384 columns (`XFD`). Attempting column `16,385` throws `ArgumentOutOfRangeException`.
  - **Cell Text Length:** 32,767 characters (Excel's per-cell string limit). Cells with 32,767 characters write and read without truncation.
  - **Worksheet Name Length:** Exactly 31 characters permitted. A 32-character name throws `ArgumentException`.
  - **Forbidden Characters:** Sheet names containing `\`, `/`, `?`, `*`, `[`, `]`, `:`, or starting/ending with `'` are strictly rejected.
- **Result:** **PASS (All Excel boundaries strictly enforced with clear ArgumentException messages)**.

### Group 9: PDF Visual Regression & Geometry (`PdfVisualRegressionTests.cs`)
- **Objective:** Verify vector layout calculations, A4 landscape margins, and text extractability from rendered PDF binaries.
- **Geometry & Typography Checks:**
  - Page dimensions strictly match A4 Landscape: `842 x 595.28 pt`.
  - Chart plotting canvas strictly respects margins: `left: 28.35 pt`, `top: 28.35 pt`, `right: 813.65 pt`, `bottom: 555.6 pt`.
  - Statistical process control (SPC) lines: UCL, CL, and LCL lines are drawn within chart bounds.
  - Text Extraction: Verified via `UglyToad.PdfPig` that rendered Turkish text (`Analiz Raporu`, `Üretim Kalite Testi`, `Sayfa 1 / 2`) is extractable and not rasterized into unsearchable bitmaps.
- **Result:** **PASS (100% vector paths, text extractable, correct bounding boxes)**.

### Group 11: Cross-Platform & Culture Invariance (`CrossPlatformAndCultureTests.cs`)
- **Objective:** Ensure numeric and date serialization in XLSX XML is strictly culture-invariant regardless of the host OS locale or thread culture.

- **Docker / Linux Headless:** Embedded Liberation Sans TrueType fonts guarantee PDF rendering without requiring system-installed fonts on Linux containers.
- **Result:** **PASS (100% culture-invariant XML serialization)**.

## 9. Discovered & Repaired Defects

| ID | Severity | Component | Issue & Impact | Solution Implemented |
|:---:|:---:|:---|:---|:---|
| **DEF-001** | High | `CellAddress.cs` | `CellAddress.Parse` did not enforce Excel boundaries (`row <= 1,048,576` or `col <= 16,384`), allowing invalid addresses like `A1048577` or `XFE1`. | Added explicit row and column boundary checks throwing `ArgumentException`. |
| **DEF-002** | High | `StreamingPackageWriter.cs` | Allowed invalid characters (`\ / ? * [ ] :`), leading/trailing apostrophes (`'`), and duplicate sheet names. | Enforced Excel sheet naming rules and duplicate tracking via `HashSet<string>`. |
| **DEF-003** | Medium | `ExcelCell.cs` | Integer cells or whole-number formulas returned `null` when accessed via `GetDouble()` or `GetDecimal()`. | Extended numeric getters to seamlessly cross-convert whole numbers and decimals. |
| **DEF-004** | Medium | `ExcelStreamingWorksheet.cs` | Allocated `new ExcelStreamingRowWriter` on every row (1M allocations on 1M rows). | Reused internal row writer instance per worksheet, resetting column counter. |
| **DEF-005** | High | `OpenXmlWorkbookWriter.cs` & `StreamingPackageWriter.cs` | Raw control characters (`\0`..`\x1F`) caused unhandled `XmlException` from .NET `XmlWriter`. | Added `SanitizeXmlString` to strip illegal XML 1.0 characters. |
| **DEF-006** | High | `PdfFontResolver.cs` | Re-read 2.5 MB embedded TrueType font files from manifest stream on every font request. | Cached embedded font byte arrays in static `ConcurrentDictionary<string, byte[]>`. |
